# API reference

_Generated by `npm run docs:api` from the route source. Do not edit by hand._

All paths are under the API origin. Bodies are JSON and validated with zod; errors are `{ error, message, details? }`. Authentication is an HttpOnly session cookie. Checkout requires an `Idempotency-Key` header. Every money value is integer cents (CAD). Resource-level checks (own order, own store, own deliveries) are enforced inside each handler and covered by tests.
